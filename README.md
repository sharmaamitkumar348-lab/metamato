# Metamato - Food Delivery Platform

A modern, fast, and beautiful food delivery and restaurant discovery platform inspired by Zomato.

✨ **User Interface**
- Clean, modern design with glassmorphism effects
- Responsive mobile-first approach
- Dark mode compatible
- Smooth animations and transitions
- Live cart with real-time calculations

🍽️ **Core Features**
- Restaurant discovery and browsing
- Advanced search and filters
- Cuisine categories
- Popular dishes showcase

- Dynamic cart management
- Special deals and offers
- Live delivery status updates

🎨 **Design**

## Getting Started

### Prerequisites
- Node.js 16.0.0 or higher
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sharmaamitkumar348-lab/metamato.git
cd metamato
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to:
```
http://localhost:3000
```

## Build for Production

```bash
npm run build
```

The optimized production files will be in the `dist` directory.

## Customization

### Colors
Edit `tailwind.config.js` to customize the color scheme:
```javascript
colors: {
  brand: {
    500: '#your-color',
  },
}
```

### Content
Update restaurant, category, and dish data in respective component files.

### Images
Replace image URLs with your own or use a local image directory.
